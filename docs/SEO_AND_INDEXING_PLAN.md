# OrbitSM SEO and Indexing Plan

## Current Public Assets

- GitHub showcase repository: https://github.com/sanjit-bose/orbitsm-showcase
- Static showcase page: `index.html`
- Public-safe screenshots: `screenshots/`
- Architecture and feature docs: `docs/`
- Sitemap: `sitemap.xml`
- Robots file: `robots.txt`

## Recommended GitHub Pages Setup

1. Open the repository settings for `orbitsm-showcase`.
2. Go to **Pages**.
3. Set source to `Deploy from a branch`.
4. Select branch `main`.
5. Select folder `/root`.
6. Save.

Expected URL:

```text
https://sanjit-bose.github.io/orbitsm-showcase/
```

## Google Search Console Steps

1. Add the GitHub Pages URL or custom domain to Google Search Console.
2. Verify ownership using the method Google provides.
3. Submit the sitemap URL:

```text
https://sanjit-bose.github.io/orbitsm-showcase/sitemap.xml
```

4. Use URL Inspection to request indexing for the homepage.
5. Recheck indexing after 7, 30, and 60 days.
